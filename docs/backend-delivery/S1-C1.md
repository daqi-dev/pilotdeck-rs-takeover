## 实现与资源归属

恢复先保留原始 session key 的 reservation，校验归档，并取得最终路径的 canonical fence。相同文件的 sanitize 别名因此串行处理。owned blocking closure 持有 reservation、fence 和既有 cold writer lease，直至临时文件清理或完整发布结束；caller future 取消仅置取消标记，不能提前释放这些资源。

写入复用 storage 已有同目录唯一临时文件及 RAII，使用原 `TranscriptWriter::for_store`、原 metadata 和 accepted_input 记录方法。没有复制 JSONL 序列化，字段顺序、sequence、parentEntryId、turnId 和内容沿用原 writer。各写入阶段及最终提交前检查取消，文件 `sync_all` 后通过同目录 `hard_link` 原子发布完整 inode，再清理自己拥有的临时名字。发布失败不退回覆盖 rename。

目标占用检查使用 `symlink_metadata`，普通文件、目录、活 symlink 和悬 symlink 都返回 `SESSION_RESTORE_CONFLICT`，不会改动原目标。最终发布时外部创建者不必参与内部锁，`hard_link` 仍拒绝覆盖。该安全差异仅限占用和竞争，登记为 [S1-RESTORE-NO-REPLACE-001](../../specs/gateway-parity/diffs/S1-RESTORE-NO-REPLACE-001.md)；中段失败不暴露最终文件属于对齐 TS 原子恢复，不借差异放宽。

错误转换区分 `LedgerError::Io` 与非 I/O 错误。优先复用 `node_io` 已有 Stage 的真实 syscall/path；直接 lstat、fsync、link 边界提供实际来源。无 Stage 的 StorageStimulus EIO 只保留 errno/code 和原错误文字，不猜 syscall/path，也不复制 TS preload 的人工文案。新 `try_writer_lease_storage` 保留结构化错误，原 `try_writer_lease` 签名和映射不变。既有 Rust-only `LedgerLock::acquire` 对 lock open 主动擦除 errno 的边界保持原样，不从文字反推错误码。冲突和归档校验专用错误码保持不变。

取消与最后一次提交之间存在正常竞争，允许结果为没有最终文件或已发布完整文件；不承诺提交点之后取消仍可同 key 重试。SIGKILL 无法执行 RAII，可能遗留独立 stage，但不生成半份最终 `.jsonl`。下次使用新 stage，不扫描删除其他写入者临时文件。本包未声称已证明掉电持久性。
