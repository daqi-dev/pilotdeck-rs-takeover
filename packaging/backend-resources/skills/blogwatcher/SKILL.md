# blogwatcher

List subscriptions first, distinguish adding a feed from marking an entry read, and preserve entry identifiers in reports. Fetch only feeds relevant to the request. Report retrieval failures separately from feeds with no new entries. Do not subscribe, unsubscribe or mark entries read unless the current task authorizes that change.

The optional external command is `blogwatcher`. Inspect `blogwatcher --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
