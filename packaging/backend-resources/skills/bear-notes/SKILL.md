# bear-notes

Resolve a note identifier from a search before modifying it. Read existing text and tags and preserve unrelated content. Check authentication through the CLI without printing tokens. Verify a write by reading the note again. Bear and its local authorization are external requirements; this resource does not install or authorize them.

The optional external command is `grizzly`. Inspect `grizzly --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
