# apple-reminders

Resolve the intended list and reminder identifier before changing an item. Preserve due-date timezone, completion state, notes and recurrence unless the task changes them. Read back created or updated items. Distinguish calendar dates from a particular local time. Access to Reminders requires macOS and user-granted permission.

The optional external command is `remindctl`. Inspect `remindctl --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
