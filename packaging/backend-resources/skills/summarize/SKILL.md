# summarize

Retrieve or read the requested source before summarizing it. Preserve the distinction between the author statements and your inferences. Include the requested length, audience and source links. For audio or video, use an available transcript and disclose missing sections. An inaccessible source requires a clear limit, not invented contents. If using the optional summarize CLI, check its version and account requirements first; do not upload private files without authorization.

The optional external command is `summarize`. Inspect `summarize --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
