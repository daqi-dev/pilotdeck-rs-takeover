# trello

Resolve board, list and card IDs before changing anything. Fetch current card state and preserve labels, members and due date unless requested. Paginate list results and distinguish archived items. Keep credentials outside URLs and logs. Create or move cards only within the requested board and read back the result. This skill requires a configured API client or CLI; it does not provision an account.
