# skill-creator

Define realistic trigger requests and the observable result before writing instructions. Give SKILL.md a unique name and a concise description, then include only decisions the model needs for this workflow. Link detailed references at the point of use. Add scripts when deterministic behavior improves reliability, and execute success and failure cases. Check the real loader catalog and rendered prompt, not merely filenames. Keep external dependencies and unfinished capabilities explicit.
