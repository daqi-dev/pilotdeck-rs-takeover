# find-skills

Search the skill catalog and read descriptions before loading full instructions. For an external candidate, inspect its source, license, scripts and required accounts before recommending installation. Explain what it enables and what remains external. Finding a skill does not authorize running its scripts or changing global configuration. Prefer an existing exact capability over adding a duplicate.
