# diagram-maker

Choose SVG for a static editable drawing, HTML for interaction, or Excalidraw JSON only when the consumer requests it. Write labels and relationships before positioning boxes. Keep arrow direction consistent and avoid crossings where they obscure meaning. Give SVG a viewBox and text labels; escape user-provided XML. Open or render the result and inspect clipped labels and contrast. Include the editable source with any requested image export.
