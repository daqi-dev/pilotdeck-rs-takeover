# tmux

List sessions and panes, then bind every operation to the intended target. Capture existing output before sending keys. Separate text insertion from the Enter key so a prompt can be reviewed. For long input, use a buffer rather than reconstructing shell quoting. Verify completion from pane output and process status. Do not type into another task pane or kill unowned sessions.

The optional external command is `tmux`. Inspect `tmux --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
