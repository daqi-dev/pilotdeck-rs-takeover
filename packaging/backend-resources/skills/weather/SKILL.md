# weather

Resolve the place and timezone before comparing forecast periods. Use an available weather service with observation or forecast timestamps. State units and separate current conditions from a future forecast. Do not substitute old climate averages for current data. If no network or configured provider is available, report that limitation. A remote query may reveal the requested location; use only the location necessary for the task.
