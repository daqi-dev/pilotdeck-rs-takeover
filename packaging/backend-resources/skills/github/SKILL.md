# github

Resolve repository owner/name before issuing API or CLI requests. Inspect PR diffs and test evidence rather than relying on titles. Keep issue and PR identifiers in reports. Read auth status without exposing credentials. Prepare reviewable content before a requested write; pushing, merging, publishing, closing and commenting require authorization from the current task. Use a body file for multiline text.

The optional external command is `gh`. Inspect `gh --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
