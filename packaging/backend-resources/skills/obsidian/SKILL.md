# obsidian

Select the vault explicitly and distinguish the vault path from an application URI. Preserve frontmatter and existing links when editing Markdown. Resolve ambiguous note names by path. Use a new output for exports and inspect backlinks when renaming a note. The Obsidian application and any CLI integration are external dependencies; do not modify unrelated vault plugins or settings.

The optional external command is `obsidian`. Inspect `obsidian --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
