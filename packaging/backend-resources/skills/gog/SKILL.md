# gog

Identify the active account and required service before a request. Use stable resource IDs from list or search results. Read before editing a document, calendar event or contact. Preserve timezone and attendees when changing an event. Confirm the observed result after a mutation. OAuth scopes and account setup are external prerequisites; do not print refresh tokens or broaden account access.

The optional external command is `gog`. Inspect `gog --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
