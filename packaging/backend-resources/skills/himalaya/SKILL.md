# himalaya

Select the account and mailbox explicitly. Fetch a message by its mailbox-local identifier before replying or forwarding; retain conversation headers through the CLI reply operation. Draft first, then send only when authorized. A failed listing is not an empty inbox. Review recipients, subject and attachments immediately before sending. Mail credentials belong to the external account configuration and must not enter project files.

The optional external command is `himalaya`. Inspect `himalaya --help` and its installed version before selecting version-dependent options. Missing software or an unauthorized account is an unavailable dependency, not a successful operation.
