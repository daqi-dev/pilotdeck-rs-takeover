# frontend-slides

Build one semantic section per slide and keep content within the viewport at the agreed aspect ratio. Add keyboard navigation and a visible position indicator. Respect reduced-motion preferences. Keep the document usable without remote fonts or a network connection when portability matters. Test first and last slide, resizing and print output. A native PPTX request belongs to the pptx skill; HTML is not a substitute for editable PowerPoint.
