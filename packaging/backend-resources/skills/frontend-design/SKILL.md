# frontend-design

Start with the intended user action, the available content and the target viewport. Choose an explicit type scale, spacing rhythm and limited color palette. Use semantic controls with visible focus, usable contrast and labels. Implement loading, empty and error states alongside successful content. Inspect at narrow and wide widths, and check keyboard navigation. Keep implementation notes out of user-facing copy unless they help a decision.
