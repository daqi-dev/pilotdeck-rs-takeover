# web-design-guidelines

Walk through the primary user action at desktop and narrow viewport widths. Check focus order, labels, contrast, touch targets, error recovery and the relationship between loading and final layout. Record concrete failures with an element or route and reproduction steps. Prioritize blocked actions over style preferences. Verify a recommended fix in the rendered page rather than assuming a CSS change improved the result.
