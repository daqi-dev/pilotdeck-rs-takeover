# react-next-best-practices

Use the project locked versions and router conventions. Keep secrets and server-only APIs outside client bundles. Minimize client boundaries and serialize only necessary props. Load independent data concurrently where that preserves error handling. Check effect cleanup, stable list keys and hydration consistency. Measure a suspected rendering or bundle issue before adding caching. Describe findings with the affected file and the user-visible failure.
