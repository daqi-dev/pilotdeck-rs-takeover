# browser-use

Use the browser-use MCP tool catalog rather than assuming tool names from another client. Take a fresh accessible snapshot after navigation and locate controls by observed roles and labels. After submitting a change, inspect the resulting state before claiming success. The external Playwright MCP service, supported Node runtime and browser must be installed separately; backend core remains independent of them. Browser login and external mutations follow the current task authorization.
